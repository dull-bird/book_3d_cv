# 模块 D：点云处理与分析

> **一句话**：点云是 3D 视觉的"通用语"——深度估计、双目匹配、SfM、LiDAR 的输出都是点云。但点云是离散的、无序的、稀疏的。学会在点云上做分类、分割、配准、检测，才能打通从传感器到理解的最后一公里。

## 为什么这个模块重要

前面几个模块教你"如何获得 3D 信息"——单目猜深度、双目算视差、SfM 重建点云。但这个模块要回答一个更根本的问题：**拿到点云之后呢？**

一堆 XYZ 坐标有什么用？你需要知道"这是桌子还是椅子"（分类）、"这堆点里面哪些是门把手"（分割）、"把两帧扫描拼在一起"（配准）、"房间里有哪些物体"（检测）。这些是 3D 感知的核心任务，是自动驾驶、机器人抓取、AR/VR、工业检测的刚需。

更重要的是，点云上的深度学习迫使你重新思考很多 2D 视觉中理所当然的东西。图像是规整的网格——每个像素有固定的邻居，卷积核滑过去就行。点云没有网格、没有顺序、密度不均匀。怎么设计网络架构来处理这种不规则数据？这是本模块要讲的核心故事。

## 关键论文速览

| 年份 | 工作 | 核心贡献 |
|------|------|---------|
| 1992 | Besl & McKay, *ICP* | 迭代最近点，点云配准奠基算法 |
| 2016 | Zhou et al., *FGR* | 快速全局配准，FPFH+鲁棒优化 |
| 2017 | Qi et al., *PointNet* (CVPR) | 首个直接处理原始点云的深度网络，对称函数保证置换不变 |
| 2017 | Qi et al., *PointNet++* (NeurIPS) | 层级结构 + 集合抽象，点云的"CNN化" |
| 2019 | Thomas et al., *KPConv* (ICCV) | 核点卷积，在 3D 空间定义可变形卷积核 |
| 2019 | Qi et al., *VoteNet* (ICCV) | 霍夫投票做 3D 目标检测，纯几何驱动 |
| 2021 | Yang et al., *TEASER++* (T-RO) | 可认证鲁棒配准，容忍 90%+ 外点 |
| 2021 | Zhao et al., *Point Transformer* (ICCV) | 自注意力机制用于点云 |
